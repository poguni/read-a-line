## 1. 디자인 원칙

1. **한 칸의 성취를 크게** — 책 한 권을 칸에 놓는 순간과 줄이 완성되는 순간이 화면에서 가장 눈에 띄어야 합니다.
2. **테마는 옷, 기능은 몸** — 세 테마는 색·글꼴·모양만 다르고, 화면 구성·순서·문구·동작은 같습니다.
3. **숫자는 친절하게** — 진행률과 필요 속도는 "11일에 1권"처럼 바로 행동으로 옮길 수 있는 말로 보여 줍니다.
4. **넓은 화면은 넓게** — 데스크톱에서는 가운데에 좁게 모으지 않고 화면 전체 너비를 씁니다.
5. **색만으로 말하지 않기** — 칸 상태는 색과 함께 책 제목·체크 표시·테두리로도 구분합니다.

## 2. 테마 개요

| 키(`data-theme`) | 이름 | 콘셉트 | 분위기 키워드 |
|---|---|---|---|
| `library` | **고풍 서재** (Library Classic) | 오래된 서재와 도서관, 가죽 장정과 황동 장식 | 차분함 · 무게감 · 클래식 |
| `pop` | **빙고 팝** (Bingo Pop) | 빙고 게임장, 빙고 공과 도장 | 경쾌함 · 귀여움 · 놀이 |
| `modern` | **모던 마일스톤** (Modern Milestone) | 꾸준함이 쌓여 목표에 닿는 대시보드 | 세련됨 · 명료함 · 성취 |

- 테마는 `<html data-theme="library|pop|modern">` 값 하나로 바뀌고, 모든 색·글꼴·모양은 CSS 변수로 정의합니다.
- 기본 테마는 `library`이며, 선택한 테마는 설정(`settings.theme`)에 저장합니다.

### 3.2 빙고 칸 색상 (4가지 상태)

| 상태 | 의미 | 고풍 서재 | 빙고 팝 | 모던 마일스톤 |
|---|---|---|---|---|
| 빈 칸 | 아직 책을 놓지 않음 | `#F8F1E0` 바탕, `1px dashed #8A7357` | `#FFFFFF` 바탕, `2px solid #2B2433` | `#FFFFFF` 바탕, `1px solid #DCDAD4` |
| 채운 칸 | 책을 놓음 | `#24412F` 바탕, 글자 `#F3EAD4` | `#FFD84D` 바탕, 글자 `#2B2433` | `#121417` 바탕, 글자 `#FFFFFF` |
| 빙고 줄 | 완성된 줄에 속한 칸 | `#6E2230` 바탕, `2px solid #D9BF8A` | `#4FD1B0` 바탕, 잉크 테두리 | `#3550E6` 바탕, 글자 `#FFFFFF` |

- 채운 칸과 빙고 줄 칸에는 **미션(작게) + 책 제목(크게)** 을 함께 적고, 오른쪽 위에 체크 표시를 둡니다(모던 테마는 체크 생략, 정렬로 구분).
- 완성된 줄 위에는 반투명 선(`--line-stroke`, 굵기 `--line-w`)을 긋습니다: 고풍 `#F3D99A` 5px · 팝 `#2B2433` 4px · 모던 `#FFFFFF` 3px, 평소 불투명도 0.3.

## 4. 레이아웃

### 4.1 기준 화면과 분기점

| 구분 | 기준 크기 | 분기 |
|---|---|---|
| 스마트폰 | 390×844 | 너비 1023px 이하 |
| 데스크톱 | 1440×900 (16:10) | 너비 1024px 이상 |

- 360px부터 1920px 이상까지 **가로 스크롤이 생기지 않아야** 합니다.

### 4.2 데스크톱 (≥1024px) — 화면 전체를 넓게

```
┌──────────┬──────────────────────────────────────────────────────────┐
│ 사이드바  │  페이지 제목                         [섞기] [공유] [+ 추가] │
│ 256px    ├───────────────────────────────┬──────────────────────────┤
│ · 브랜드  │                               │  연간 목표 요약 카드       │
│ · 메뉴 5 │        큰 빙고판               │  필요 속도 · 남은 기간 · 예상│
│ · 테마   │   (화면 높이 − 215px,           │  빙고 현황                │
│ · 진행   │    1440×900에서 약 700px)       │  칸에 놓지 않은 책         │
│   요약   │                               │  최근 읽은 책 (넓으면 2열)  │
└──────────┴───────────────────────────────┴──────────────────────────┘
```

| 화면 | 데스크톱 배치 |
|---|---|
| 빙고판 | 2단: 왼쪽 큰 빙고판, 오른쪽 정보 패널(최소 360px, 남는 너비 모두 사용) |
| 진행률 | 12열 그리드: 달성률(5) · 기간 비교+속도(7) / 월별 그래프(8) · 빙고 현황+올해의 기록(4) |
| 책장 | 책 카드 자동 열(최소 260px) — 1440에서 4열 |
| 설정 | 2열 카드, 테마 선택은 전체 너비 |
| 판 관리 | 판 카드 자동 열(최소 420px) — 1440에서 2열. 카드: 미니 격자 미리보기(96px) + 이름 + "지금 쓰는 판" 태그 + 연도·크기·빙고 줄·채운 칸·만든 날 + [빙고판 보기 / 이 판 쓰기][삭제]. 지금 쓰는 판은 강조색 윤곽선 |
| 새 빙고판 만들기 | 온보딩과 같은 화면(제목 "새 빙고판 만들기", 지금 값으로 미리 채움, 빙고판 이름 입력 추가, "돌아가기" 버튼) |
| 온보딩 | 좌우 분할: 왼쪽 소개와 빙고판 그림(사이드바 색), 오른쪽 입력 양식 |
| 대화상자 | 화면 가운데 창. 책 추가는 왼쪽 입력·오른쪽 칸 선택판(최대 980px) |

### 4.3 스마트폰 (<1024px)

- 위: 상단 바(브랜드, 공유, 설정) → 페이지 제목 → 간단한 진행 요약 카드
- 가운데: 크기 선택 + 빙고 수 → 빙고판(가로 꽉 차게) → "읽은 책 추가" 큰 버튼 + 섞기·공유 아이콘 버튼
- 아래: 보조 카드(필요 속도, 빙고 현황, 미배치 책, 최근 책) → 하단 탭 메뉴 5개(빙고판·책장·진행률·판 관리·설정)
- 대화상자는 아래에서 올라오는 시트로 표시합니다.

| **동기화 상태** | 알약 모양 작은 표시(12px): 점 + 저장됨 · 저장 중(점 깜빡임) · 오프라인(빈 점) · 저장 실패(`--bad` 점) · 저장 안 함(둘러보기). 데스크톱은 사이드바 아래, 모바일은 상단 바 | 바탕 `rgba(127,127,127,.16)`, 글자는 주변 글자색 |
| **둘러보기 안내 띠** | 본문 맨 위, 점선 테두리 + `--surface-2` 바탕, "둘러보기 끝내기" 작은 버튼 | 공통 |
| **앱 제목(브랜드)** | 사이드바·상단 바의 아이콘 + "한 줄 독서" + 영문은 하나의 버튼이며, 누르면 빙고판 화면으로 가요. 마우스를 올리면 옅은 바탕 | 공통 |
| **로그인 화면** | 온보딩과 같은 좌우 분할(왼쪽 소개·빙고판 그림), 오른쪽 이메일·비밀번호, "로그인"(주요) + "샘플 데이터로 둘러보기"(보조). 가입 버튼 없음 | 온보딩과 같음 |

## 8. 접근성 체크리스트

## 10. 구현 메모

- 토큰은 `:root`와 `[data-theme="…"]` 블록에 CSS 변수로 정의하고, 컴포넌트는 변수만 참조합니다. 테마별 차이가 변수로 표현되지 않는 경우에만 `[data-theme="pop"] .size-btn{…}`처럼 테마 선택자를 씁니다.
- 빙고판은 `grid-template-columns: repeat(var(--n), minmax(0,1fr))`와 `container-type: inline-size`를 써서 3×3·4×4·5×5에 같은 코드로 대응합니다.
- 새 테마를 추가할 때는 3장의 토큰 표에 한 열을 더하고, 3.2절 칸 상태 4가지와 5장 컴포넌트 표현을 모두 정한 뒤 구현합니다.
- 시안 파일은 앱을 샘플 데이터(데모 모드, 저장 안 함)로 띄워 보여 주므로, 앱을 고치면 시안도 다시 만들어 맞춥니다.
