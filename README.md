# 한 줄 독서 (Read a Line)

> 한 권 읽으면 한 칸, 한 줄 채우면 빙고!

연간 독서 목표를 **빙고판과 미션**으로 바꿔, 여러 분야의 책을 즐겁게 꾸준히 읽도록 돕는 개인용 웹앱입니다.
"올해 24권 읽기" 같은 숫자 목표는 중간에 동기를 잃기 쉽습니다. 한 줄 독서는 "500쪽 넘는 책", "번역서", "과학 교양서" 같은 미션 칸을 채우며 빙고를 완성하는 재미로 독서를 이어 가게 합니다.

## 주요 기능

- **빙고판 만들기** — 3×3(9권) · 4×4(16권) · 5×5(25권) 중에서 고르고, 44개 미션 중 분야가 고르게 섞이도록 자동 추천합니다. 가운데 FREE 칸, 미션 직접 수정, 빈 칸 미션 다시 섞기를 지원합니다.
- **읽은 책 기록** — 제목·저자·완독일·쪽수·별점·태그·한 줄 메모를 남기고, 쪽수와 태그에 맞는 칸을 추천받아 놓습니다.
- **빙고 연출** — 줄이 완성되면 칸이 빛나고 줄이 그어지며 BINGO 배지와 색종이가 나옵니다. 모든 칸을 채우면 블랙아웃 축하 화면이 열립니다. 효과음도 켤 수 있습니다.
- **칸 끌어서 옮기기** — 마우스로 끌거나, 휴대폰에서는 길게 누른 뒤 옮겨 칸 위치를 바꿉니다.
- **빙고 보상** — "1줄 완성 → 갖고 싶던 책 사기, 3줄 완성 → 여행 가기"처럼 줄 수마다 나에게 줄 보상을 정해 둡니다.
- **진행률** — 목표 대비 달성률, 기간 경과와 비교한 진행 상태, "10일에 1권" 같은 필요 속도, 연말 예상 권수, 월별 완독 그래프를 보여 줍니다.
- **판 관리** — 여러 빙고판을 만들어 바꿔 쓰거나 삭제할 수 있습니다. 판을 지워도 읽은 책은 책장에 남습니다.
- **공유** — 빙고판을 SNS용 이미지(1080×1350 PNG)로 저장하거나, 빙고판 코드로 친구에게 같은 판을 보냅니다.
- **테마 3종** — 고풍 서재 · 빙고 팝 · 모던 마일스톤. 겉모습만 바뀌고 기능과 기록은 같습니다.
- **로그인과 동기화** — 계정에 기록이 저장되어 여러 기기에서 같은 기록을 씁니다. 오프라인일 때 바꾼 내용은 연결되면 저장됩니다. JSON 백업·복원도 지원합니다.

## 사용 방법

1. 앱 주소(GitHub Pages)를 열거나 `index.html` 파일을 브라우저로 엽니다.
2. **Delicious Library와 같은 계정**(이메일 + 비밀번호)으로 로그인합니다. 이 앱에서는 새 계정을 만들지 않습니다.
   - 로그인 없이 구경하려면 **샘플 데이터로 둘러보기**를 누르세요. 둘러보기에서는 아무것도 저장되지 않습니다.
3. 처음 화면에서 테마, 연간 목표 권수, 빙고판 크기를 고르고 **빙고판 만들기**를 누릅니다.
4. 책을 다 읽으면 **읽은 책 추가**를 눌러 기록하고, 어울리는 칸에 놓습니다.
5. 한 줄이 완성되면 빙고! **빙고 보상**에 정해 둔 보상을 챙기세요.
6. **진행률** 메뉴에서 목표까지 얼마나 남았는지, 어떤 속도로 읽으면 되는지 확인합니다.

## 기술 구성

| 항목 | 내용 |
|---|---|
| 앱 | `index.html` 파일 하나(HTML · CSS · 바닐라 JavaScript), 빌드 과정 없음 |
| 저장 | Supabase — Delicious Library 프로젝트를 함께 쓰되, 전용 스키마 `read_a_line`에 따로 저장 |
| 보안 | 모든 테이블에 RLS(본인 기록만 읽고 쓰기). 앱에는 공개(publishable) 키만 들어 있습니다 |
| 캐시 | 브라우저 localStorage(빠른 첫 화면, 오프라인 읽기, 저장 대기) |
| 외부 라이브러리 | `@supabase/supabase-js@2.45.4`(CDN), Google Fonts |

## 폴더 구조

```
├─ index.html              # 앱 본체
├─ docs/                   # 기획 문서 (PRD_한줄독서.md 원본, .html 보기용)
├─ design/                 # 디자인 가이드(DESIGN.md)와 테마별 시안 3종
└─ supabase/migrations/    # read_a_line 스키마 SQL
```

## 직접 설치할 때 (Supabase)

1. `supabase/migrations/`의 SQL을 파일 이름 순서대로 Supabase 프로젝트에 적용합니다.
2. 대시보드 **Project Settings → Data API → Exposed schemas**에 `read_a_line`을 추가합니다.
3. `index.html`의 `SUPABASE_URL`, `SUPABASE_KEY`를 내 프로젝트의 URL과 공개 키로 바꿉니다. **`service_role` 키는 절대 넣지 마세요.**

자세한 요구사항은 [`docs/PRD_한줄독서.md`](docs/PRD_한줄독서.md), 디자인 규칙은 [`design/DESIGN.md`](design/DESIGN.md)를 참고하세요.
